# 📚 Sistem Informasi PAUD (SIMPAUD)

## Deskripsi

Sistem Informasi PAUD (SIMPAUD) merupakan aplikasi berbasis web
yang dirancang untuk membantu administrator dalam mengelola seluruh data
akademik dan administrasi sekolah secara terintegrasi. Sistem ini
memudahkan pengelolaan data siswa, guru, perangkat pembelajaran, hingga
administrasi keuangan sehingga proses pengelolaan sekolah menjadi lebih
efektif, efisien, dan terdokumentasi dengan baik.

## Tujuan

-   Mempermudah administrator dalam mengelola data sekolah.
-   Menyediakan informasi akademik yang terstruktur dan mudah diakses.
-   Mendukung digitalisasi administrasi sekolah.
-   Mengurangi penggunaan dokumen secara manual.

## Fitur Administrator

-   Materi Pembelajaran
-   Kalender Pendidikan
-   Program Semester (Prosem)
-   RPPM (Rencana Pelaksanaan Pembelajaran Mingguan)
-   RPPH (Rencana Pelaksanaan Pembelajaran Harian)
-   Penilaian Siswa
-   Data Siswa
-   Data Guru
-   Pengelolaan Keuangan SPP

## Teknologi

-   HTML5
-   CSS3
-   JavaScript
-   PHP
-   MySQL
-   Bootstrap

## Cara Menjalankan

1.  Install XAMPP.
2.  Jalankan Apache dan MySQL.
3.  Import database ke phpMyAdmin.
4.  Letakkan folder project pada `htdocs`.
5.  Akses `http://localhost/simpaud`.
